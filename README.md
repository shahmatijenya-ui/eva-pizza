# Ева, у меня к тебе пицца ♡

Личное приглашение на вечер. Svelte 5, Vite, Three.js. Все звуки синтезируются в браузере, аудиофайлы не нужны. Сайт не отправляет ответы и не собирает данные.

Вопросы занимают один экран без прокрутки. На каждом шаге только два ответа: после выбора появляется полноэкранная реакция и автоматически открывается следующий вопрос. На последнем вопросе кнопка «Нет» превращается в свинку, шесть раз перемещается, затем лопается со звуком. Главная 3D-свинка остаётся в кадре, переключателей звука и кнопок подтверждения нет.

```sh
npm install
npm run dev
npm run build
```

Исходники хранятся в `main`, готовый сайт публикуется из ветки `gh-pages`. GitHub Pages обновляется автоматически после загрузки новой сборки в `gh-pages`. Для сборки в подпапку используется переменная `VITE_BASE_PATH=/eva-pizza/`. Шрифты, 3D и звуки загружаются с того же сайта, без внешних сервисов.

Для Vercel: framework Vite, build command `npm run build`, output directory `dist`.

Маршрут пока является художественной схемой Донецка, а не точной картой и не навигацией. Перед публикацией необходимо проверить названия улиц: в исходном запросе «Багратиону, 51» и «Вашникрадского, 21». Они вынесены в `src/App.svelte` в объект `addresses`. Ссылки с личными адресами не стоит размещать публично.
